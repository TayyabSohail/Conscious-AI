# Docs

| Area | Folder | Covers |
|------|--------|--------|
| **Product** | [product/](./product/README.md) | Requirements, product rules, decisions, and open questions: *what* we build and *how it behaves* |
| **Engineering** | [engineering/](./engineering/README.md) | System and security architecture, codebase guides, coding standards: *how* it's built |

Product docs never prescribe implementation. Engineering docs implement product rules and never reinterpret them. Requirement IDs (`FR-`, `NFR-`, `SEC-`, `PLT-`) and decision IDs (`D-`) link the two.
